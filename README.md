# homebrew-pinchboard

Homebrew tap for [Pinchboard](https://github.com/zrsvfr9ytd-lab/pinchboard).

```sh
brew install --cask zrsvfr9ytd-lab/pinchboard/pinchboard
```

Pinchboard is not notarized. On first launch: System Settings → Privacy & Security → “Open Anyway”,
or `xattr -dr com.apple.quarantine /Applications/Pinchboard.app`.
